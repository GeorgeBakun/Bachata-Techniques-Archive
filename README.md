# Архив бачаты

Статический каталог видеоуроков для GitHub Pages. Видео остаются в VK; в репозитории хранятся описания и iframe-коды.

## Состав
- `index.html` — страница каталога.
- `styles.css` — оформление.
- `app.js` — поиск, фильтры, сортировка и VK-плеер.
- `videos.json` — каталог роликов.
- `favicon.svg` — иконка.

## Добавление ролика
Добавь объект в массив `videos.json`:

```json
[
  {
    "id": "lesson-001",
    "title": "Базовый шаг с переносом веса",
    "description": "Разбор переноса веса и положения корпуса.",
    "category": "Работа ног",
    "lessonDate": "2026-10-15",
    "level": "Начинающий",
    "format": "Соло",
    "vkEmbed": "<iframe src=\"https://vk.ru/clip_ext.php?oid=-243224841&id=456239017&autoplay=1\" width=\"363\" height=\"714\" allowfullscreen></iframe>"
  }
]
```

Категория: `Работа ног`, `Работа корпуса`, `Повороты`, `Связки`, `Музыкальность`.

Уровень: `Начинающий`, `Средний`, `Продвинутый`.

Тип исполнения: `Соло`, `В паре`, `Универсальный`.

Дата урока указывается в формате `ГГГГ-ММ-ДД`. В `vkEmbed` вставляй полный iframe-код, полученный через экспорт клипа VK. Сайт извлекает адрес и принимает только HTTPS-встраивание VK с путём `clip_ext.php`.

## Включение GitHub Pages
В репозитории открой Settings → Pages. В разделе Build and deployment выбери Deploy from a branch, ветку `main`, папку `/(root)` и нажми Save. Сайт будет доступен по адресу `https://georgebakun.github.io/Bachata-Techniques-Archive/`.

## Доступность
GitHub Pages публичен. Ссылка не является паролем. Возможность воспроизведения конкретного клипа зависит от настроек доступа VK и разрешения VK на встраивание.
